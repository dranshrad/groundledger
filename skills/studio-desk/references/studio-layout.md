# Studio Layout Conventions

## Shared

- `STUDIO.md` — human conventions
- `archive/` — immutable history
- Never store API keys in the studio tree

## Blog Desk

```
drafting/<slug>/v001.md
published/<slug>.md
briefs/
archive/
```

## Longform

```
drafts/<slug>/
research/
notes/
images/
archive/
```

## Version filenames

Prefer `v001.md`, `v002.md` or `2026-07-25-a.md`.

**WARNING:** Keep the originals when vaulting.
