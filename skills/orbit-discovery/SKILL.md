# Orbit Discovery

```
Observe → Reinforce → Build → Instrument → Transmit → (repeat)
```

Groundledger discovery loop.

Keep strategy language qualitative. Use a number only if it is ledgered under the Grounding Law (`../blog-engine/references/grounding.md`).

## Modes

| Mode | Output |
|------|--------|
| `diagnose` / `triage` | **Stage Triage** — blocking ORBIT stage |
| `surfaces` / `bet` | **Surface Bet Card** |
| `echo` | **Echo Map** — off-site corroboration inventory |
| `close` | **Close Path** — conversion / BOFU brief + audit |
| `spray` | **Question Spray** — query fan-out / topical questions |
| `concord` | **Entity Concord** — naming consistency across web assets |
| `place` | **Place Signal** — local/profile/NAP pack |
| `dial` | **Orbit Dial** — visibility + revenue scorecard |

| `cluster` | Intent-pure URL graph |

| `brief` | Asset brief with evidence + KPI |
| `scorecard` | Dual buyer/machine score (legacy short form) |
| `playbook` | **Path Cards** |

## ORBIT stages

| Stage | Question |
|-------|----------|
| **O**bserve | What jobs are buyers finishing? |
| **R**einforce | Where are we corroborated off-site? |
| **B**uild | What owned asset earns trust + extraction? |
| **I**nstrument | How will we know it worked? |
| **T**ransmit | What learning feeds the next cycle? |

## Surfaces

Owned site · classic search · AI answers · community · profiles/directories · video/audio · social (`social-cast`) · sales-assisted · paid landing (when relevant).

Pick the surface that moves the **next business outcome**.

## Stage Triage (`triage`)

1. Name the business outcome.
2. Inventory the evidence.
3. Mark the blocked stage: O/R/B/I/T.
4. Name the smallest unblock asset.
5. List the claims that need verification.

When Build is next, the artifact is [references/surface-bet.md](references/surface-bet.md) (bet card).

## Echo Map (`echo`)

1. Inventory where brand facts already appear (reviews, profiles, communities, video, directories).
2. Write a gap list for Reinforce.

See [references/echo-map.md](references/echo-map.md).

## Close Path (`close`)

- Write a decision-page brief: action, proof, objections, measurement event.
- Audit existing BOFU pages the same way.

See [references/close-path.md](references/close-path.md).

## Question Spray (`spray`)

1. Expand one seed job into fan-out questions / sub-intents.
2. Cluster them into hub/spoke candidates.

Give no fake volume numbers.

## Entity Concord (`concord`)

1. Define the canonical name, the aliases and the forbidden variants.
2. Check the site + profiles + key mentions for drift.

## Place Signal (`place`)

Local/profile pack: categories/services consistency, NAP corroboration, service-page jobs, review themes. See [references/place-signal.md](references/place-signal.md).

## Orbit Dial (`dial`)

Extends the dual scorecard with visibility vs revenue dials. See [references/scorecard.md](references/scorecard.md).

## Provenance Shelf (`shelf`)

Project bibliography + stat registry that feeds the blog-engine claim ledgers. See [references/provenance-shelf.md](references/provenance-shelf.md).

## Signal Field (`field`)

Sketch the last-N-days discourse from search (no private API required): themes, objections, phrases for VOICE/CAST.

- N is the user's window. If the user gave no N, state the window you used.
- When useful, use API-free WebSearch with site operators.

## Path Cards (`playbook`)

saas · services · media · local · ecommerce · b2b · affiliate — [references/playbooks.md](references/playbooks.md).

## Evidence law

- Use no unsourced public statistics.
- Prefer qualitative strategy over fake benchmarks.
