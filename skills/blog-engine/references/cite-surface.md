# Cite Surface Audit

Outcome question: would an answer engine quote a passage from this page?

## Dimensions (0–5 each)

1. **Passage inventory** — self-contained claim+evidence sections
2. **Entity stability** — one primary topic, consistent names
3. **Structure** — headings, tables, lists that aid extraction
4. **Purpose fit** — the intro states the job, with no bait-and-switch
5. **Access** — declared crawlers can reach primary content + matching schema

Total /25. Ship guidance: ≥20 with no zeroed dimension, or user accepts residual.

## Process

1. List 5–10 candidate citeable passages (quote them)
2. Score dimensions
3. Patch plan (≤5 edits)
4. Optional: run `cite-probe` for adversarial questions

Schema folklore (magic FAQPage, llms.txt as Google requirement) does not raise the score alone.
