# Ship Scan

SEO + extractability checklist. Does not replace CLEAR.

## Page checks

| Area | Pass |
|------|------|
| Title | Accurate, distinctive, matches job |
| Meta description | Page-specific, honest |
| H1 | One; matches title job |
| Headings | No skips; unique labels |
| Internal links | 3–10 contextual when corpus exists |
| External links | Support claims; tier-appropriate |
| URL | Stable, readable |
| OG/social | title, description, image plan |
| Images | Alt on informative assets |
| Schema | Mirror Markup only if visible |

## Extractability

| Area | Pass |
|------|------|
| Section opens | Declarative answers |
| Entities | Stable naming |
| Tables/lists | Used only when clarifying |
| Primary content | Available without exclusive app chrome |

## Site / batch mode

For a directory:
1. Run the scan per URL.
2. Summarize Critical / High / Medium.
3. Pair it with the Job Collision Map for overlap.
